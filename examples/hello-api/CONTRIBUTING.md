# Contributing

This folder is the family's teaching example. Prefer changing it when the family
standard changes (Makefile verbs, CI caller shape, health routes, config rules).

`make check` is the gate. Keep coverage at 100% branch. See the meta-repo
[CONTRIBUTING.md](../../CONTRIBUTING.md) for the family standard and
[docs/adding-a-service.md](../../docs/adding-a-service.md) to graduate a copy.

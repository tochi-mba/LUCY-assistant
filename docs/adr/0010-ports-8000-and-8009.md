# ADR-0010: ports 8000 and 8009

**Status:** accepted
**Amends:** [ADR-0004](0004-port-assignments.md)

## Context

ADR-0004 assigned 8001–8008 and deliberately started at 8001 so keyring would not move. It
left 8000 alone — not reserved, simply unused, because at the time "whatever is free" was
the problem being solved and nothing needed a ninth number.

Two things now do: the hub ([ADR-0009](0009-the-hub-lives-here.md)), and the memory service
it will need.

The published family is the hub and **eight** services. 8005 is Media-tool, which is the
owner's own private tool rather than part of the published set ([ADR-0007](0007-public-base-hubs.md)),
so it holds a number without occupying a seat. Memory-api takes the eighth seat.

## Decision

| Service | Port |
| --- | ---: |
| **Lucy (the hub)** | **8000** |
| Keyring-api | 8001 |
| User-api | 8002 |
| Settings-api | 8003 |
| Persona-api | 8004 |
| *(Media-tool, a private tool, not part of the published family)* | 8005 |
| Web-search-api | 8006 |
| Spotify-api | 8007 |
| Environments-api | 8008 |
| **Memory-api** | **8009** *(reserved; built at M5)* |

The rest of ADR-0004 stands unchanged: compose publishes each port on the host, each image
listens on the same number inside, and the family number is the one a human types.

## Why

**The front door is 8000.** It is the number a person reaches for without being told, it is
the one thing here that a newcomer will actually type, and it sits just below the block
rather than inside it — which says what it is: the thing in front of the family, not one
more member of it.

**8009 is reserved before it is built**, because the alternative is discovering the
collision during the first compose run of a service that is otherwise finished. ADR-0004's
own argument was that gaps are worse than a table; an unwritten future entry is a gap.

**Nothing moves.** Every existing assignment is untouched, so no bookmark, script or reverse
proxy has to change. That was the expensive part of ADR-0004 and it is not repeated here.

## What it costs

`docker-compose.yml`, `README.md`'s service table, `docs/architecture.md`,
`.devcontainer/devcontainer.json`'s `forwardPorts`, `LUCY-assistant.code-workspace` and
`tests/test_compose.py` all learn a ninth number. A deployment that already used 8000 for
something else on the same host has to move that something else.

## What would change our minds

A reverse proxy that binds :443 and routes by host name would make these numbers local-only.
They would still have to be unique on a laptop, so the table would stay.
